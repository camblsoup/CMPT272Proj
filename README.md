# Windows98 Report Manager

The UI is meant to replicate the Windows98 theme as well as use a system of movable windows to contain each element of the program.
Each window can be moved by dragging it's top bar. They can also be minimized, maximized or closed using the buttons in the top right.

To host the website locally run "npm run dev" in the root directory.
The website is also available at the following link: [here](https://camblsoup.github.io/CMPT272Proj/)

To use the website for the intended project please double click on the Map application on the desktop background.
